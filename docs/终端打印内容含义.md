
## 整体配置的含义


```bash
============================================================
 BENCHMARK CONFIG
============================================================
 Env=Auto(from test_jsonl, fallback=UnrealRescue-FlexibleRoom)  Res=(640, 640)  Render=False
 Collision=False  Trajectory=False
 StateMachine: Active  RescueXY=100.0cm  PlaceXY=200.0cm  ZGate=220.0cm  SuccessRadius=200.0cm(XY+Z)
 Output: /root/autodl-tmp/rescuebench_workspace/runs/nomad-test-0827/nomad
============================================================
```


| 字段 | 实际含义 |
|---|---|
| `Env=Auto(from test_jsonl, fallback=...)` | 每个测试点优先读取 JSONL 中的 `env_id`；只有没写时才使用 FlexibleRoom |
| `Res=(640,640)` | 送入环境/模型的相机观察分辨率 |
| `Render=False` | 不保存带标注的评测帧；不代表 UE 不生成相机图像 |
| `Collision=False` | 关闭额外的碰撞检测和计数，不是关闭 UE 物理碰撞 |
| `Trajectory=False` | 不保存完整轨迹文件 |
| `StateMachine: Active` | NoMaD 只负责导航，benchmark 自动插入抱起、放下和开门动作 |
| `RescueXY=100cm` | 与伤员水平距离约小于 100 cm 后触发抱人 |
| `PlaceXY=200cm` | 与担架水平距离约小于 200 cm 后触发放人 |
| `ZGate=220cm` | 上述交互还要求高度差小于约 220 cm |
| `SuccessRadius=200cm(XY+Z)` | 实际是“XY 半径 200 cm，并另受 ZGate 限制”，不是把 XY 与 Z 数值相加 |
| `Output=.../nomad` | 程序会在你给的输出目录下再按模型名建一层目录 |

## 评测过程打印内容含义

### distance

```bash
[VINTAgent] Step 1: Model inference #1 (1.51s) phase=find_injured distance=12.1328 waypoint_idx=5 chosen_wp=[0.058116987347602844, 1.1711311340332031]
[VINTAgent] Step 2: Model inference #2 (0.15s) phase=find_injured distance=11.9952 waypoint_idx=5 chosen_wp=[0.9743696451187134, -1.798917531967163]
```

- 模型估计当前观察与目标图像在训练轨迹上大约相隔多少个采样间隔。
- 标签 12 表示“目标图像约在当前观察之后 12 个下采样轨迹步”，不代表 12 米或 12 秒。不同训练数据采样频率不同，不能直接换算成统一秒数。
- 官方 NoMaD 配置中的距离标签范围是 0～20；不相关的负样本直接使用 20。因为距离头做回归，输出可以是 12.1328 这样的连续小数，而不是整数。

### waypoint

NoMaD 每次推理输出 8 个未来航点,`waypoints[0] ... waypoints[7]`，当前nomad在`repos/RescueBench/benchmark/agents/profiles.py`中配置每次都选择第 6 个未来航点(`waypoint_idx=5`)。这比官方设置`waypoint_idx=2`远了不少。

### chosen_wp=[x,y]

- 前向和右侧为正（暂未验证）
- 它是模型预测轨迹中某个未来时刻的“机器人局部坐标航点”。也就是它大概表示距离，但不能说精确是m，因为本来也是预测的，绝对值参考意义不大  
- 根据[x, y]计算 atan 得到转角（角度），以向右为正（暂未验证），绝对值最大为 30°
- 根据[x, y]计算速度，目前是 `100x` ，被裁剪到 -100～100 之间
- `chosen_wp`的日志和控制量转换都只对 NoMaD 与 ViNT 有效。
