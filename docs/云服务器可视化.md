

## 云服务器

```bash

# 开启评估
PROJECT_ROOT=/root/autodl-tmp/rescuebench_workspace
REPO="$PROJECT_ROOT/repos/RescueBench"
ENV_PATH="$PROJECT_ROOT/conda/envs/rescue-nomad"
RUN_ROOT="$PROJECT_ROOT/runs/nomad-test-0828-visual"

cd "$REPO"

"$PROJECT_ROOT/bin/rescue-run" \
    "$ENV_PATH/bin/python" \
    benchmark/rescue_benchmark.py \
    --model nomad \
    --levels 0 \
    --episodes 1 \
    --no-collision \
    --render \
    --save-frame-every 5 \
    --enable-trajectory \
    --output "$RUN_ROOT"

# 开启转发
PROJECT_ROOT=/root/autodl-tmp/rescuebench_workspace
ENV_PATH="$PROJECT_ROOT/conda/envs/rescue-nomad"

RUN_ROOT="$PROJECT_ROOT/runs/nomad-test-0828-visual"
VIEWER_ROOT="$PROJECT_ROOT/viewer"
FRAME_PATH="$RUN_ROOT/nomad/_render_frames/latest_frame.jpg"

# 将固定查看器中的图片入口指向本次评估结果。
# 即使图片暂时还没有生成，也可以先创建软链接。
ln -sfn \
    "$FRAME_PATH" \
    "$VIEWER_ROOT/latest_frame.jpg"

"$ENV_PATH/bin/python" \
    -m http.server 8765 \
    --bind 127.0.0.1 \
    --directory "$VIEWER_ROOT"

```

## 本地PC

```bash

# 建立连接
ssh `
  -F D:\Workspace\00_MyRepo\Rescubench\autodl-ssh.config `
  -N `
  -L 8765:127.0.0.1:8765 `
  autodl-t4

# 打开自动刷新页面（不要再直接打开 latest_frame.jpg）
http://127.0.0.1:8765/

```

页面默认每 500 ms 检查一次新画面。若评估尚未执行到第一个成功的 `env.step()`，页面会显示“正在等待”；图片生成后会自动开始更新，无需手动刷新浏览器。
