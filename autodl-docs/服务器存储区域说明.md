

## 存储区域说明

| 文件路径   | `/root/autodl-fs`           | `/root/autodl-tmp/` | `/root/` |
| ------ | --------------------------- | ------------------- | -------- |
| 存储类型   | 网络共享存储                      | 本地数据盘               | 本地系统盘    |
| 空间范围   | 20 GB 以下免费；                 | 默认 50 GB；           | 30 GB    |
| 收费标准   | ￥0.01/GB/日                  |                     |          |
| 贡献范围   | 同一地区内实例共享                   | 单一实例内部              | 单一实例内部   |
| 数据可靠性  | 存储后端有多冗余副本                  | 没有冗余保障              | 没有冗余保障   |
| 性能     | IO 性能一般                     | I/O 性能更好            | I/O 性能更好 |
| 数据清空机制 | 账号连续 3 个月未登录；<br>或欠费 50 元以上 |                     |          |


### 本地盘详细对比

| 文件路径   | `/root/autodl-tmp/` | `/root/`   |
| ------ | ------------------- | ---------- |
| 存储类型   | 本地数据盘               | 本地系统盘      |
| 空间范围   | 默认 50 GB；           | 30 GB      |
| 实例关机   | 数据不会丢失              | 数据不会丢失     |
| 镜像保存   | 不会随保存镜像一起保存         | 会随保存镜像一起保存 |
| 性能     | 快                   | 一般         |



## 推荐安排

/root/autodl-tmp/                 # 高速工作区
├── projects/                     # 当前运行的代码副本
├── datasets/                     # 训练数据、解压数据
├── envs/                         # Conda 环境
├── checkpoints/                  # 高频写入中的检查点
├── outputs/                      # 实验运行输出
└── cache/                        # HF、Torch 等缓存

/root/autodl-fs/                  # 可靠、跨实例存储
├── projects/                     # 代码备份或仓库归档
├── datasets-source/              # 重要原始数据
├── checkpoints-final/            # 最佳模型与最终权重
├── results/                      # 指标、图表、论文结果
└── manifests/                    # environment.yml、requirements、实验配置

## 推荐流程
/root/autodl-fs 中保存权威副本
          ↓ 训练前复制
/root/autodl-tmp 中高速训练
          ↓ 定期/训练结束同步
/root/autodl-fs 中保存重要结果
          ↓ 再备份
外部网盘、OSS 或本地电脑
