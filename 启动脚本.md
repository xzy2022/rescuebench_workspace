

## 整体评估，不保存可视化帧
```bash
PROJECT_ROOT=/root/autodl-tmp/rescuebench_workspace
REPO="$PROJECT_ROOT/repos/RescueBench"
ENV_PATH="$PROJECT_ROOT/conda/envs/rescue-nomad"
RUN_ROOT="$PROJECT_ROOT/runs/nomad-test-0830-level_0_episodes_1"

cd "$REPO"

"$PROJECT_ROOT/bin/rescue-run" \
    "$ENV_PATH/bin/python" \
    benchmark/rescue_benchmark.py \
    --model nomad \
    --levels 0 \
    --episodes 1 \
    --no-collision \
    --enable-trajectory \
    --output "$RUN_ROOT"
```

## 重新评估某些测试点 point ，并保存可视化帧

```bash
PROJECT_ROOT=/root/autodl-tmp/rescuebench_workspace
REPO="$PROJECT_ROOT/repos/RescueBench"
ENV_PATH="$PROJECT_ROOT/conda/envs/rescue-nomad"

LEVEL=0
POINT_ID=7
RUN_ROOT="$PROJECT_ROOT/runs/nomad-visual-trajectory-test-0830-L${LEVEL}-P${POINT_ID}"

cd "$REPO"

"$PROJECT_ROOT/bin/rescue-run" \
    "$ENV_PATH/bin/python" \
    benchmark/rescue_benchmark.py \
    --model nomad \
    --levels "$LEVEL" \
    --point-ids "$POINT_ID" \
    --episodes 1 \
    --no-collision \
    --render \
    --save-frame-every 5 \
    --enable-trajectory \
    --output "$RUN_ROOT"
```

具体如何拉取可视化图片到本地web，见`docs\云服务器可视化.md`
