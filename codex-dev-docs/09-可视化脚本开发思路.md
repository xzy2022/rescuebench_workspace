

需要三个脚本：
1. 接收直接的输入(各个json文件的路径)，直接获取绘图需要的数据
2. 接收绘图的数据，和输出路径，直接绘图。
3. 外层处理日志路径，获取最新的目标输入的路径，调用1和2

开发中使用的具体数据参考`tmp\plot_nomad_xy_trajectory_pycache`

考虑到代码审查的限制，可能需要在`scripts/`下构建新的的文件夹存放各个拆分的可复用模块。

plot_data = load_xy_trajectory_data(

## 脚本3

参考脚本1的约定，但是只是输入一个日志路径，如`tmp\autodl-logs\nomad-visual-trajectory-test-0830-L0-P7`，自动解析获得其中正确的json输入路径，然后绘制图像。输入中，除了日志路径，还会对内穿透下面的参数，默认值如下。
```
level=0,
point_id=1,
episode_id=0,
trajectory_start_index=0,
output 
```
其中 output 未指定输出时，自动生成不会混淆 episode 的文件名。

```bash
Set-Location 'D:\Workspace\00_MyRepo\Rescubench'
$pythonExe = 'D:\AppData\miniconda\envs\rescuebench-local\python.exe'
$plotArgs = @(
    '-m'
    'scripts.plot_latest_nomad_xy_trajectory'
    '--log-path'
    'tmp\autodl-logs\nomad-visual-trajectory-test-0830-L0-P7'
    '--level'
    '0'
    '--point-id'
    '7'
    '--episode-id'
    '0'
    '--trajectory-start-index'
    '1'
)

& $pythonExe @plotArgs
Write-Host "exit_code=$LASTEXITCODE"
```
